# Product

## Register

product

## Users

Job seekers who apply frequently and want consistent, tailored applications. They live in Claude Code as their primary tool and interact with Spice Bag mostly through slash commands and the dashboard when reviewing or exporting. Context: focused, in-flow, task-oriented — not browsing, completing a job.

## Product Purpose

Spice Bag takes a base CV and cover letter and tailors them precisely for each job posting. It stores every application with its documents, status history, and job post, and exports print-quality PDFs. The dashboard is the review surface; the real work happens via Claude Code slash commands.

## Brand Personality

Sharp, efficient, unpretentious. The chili metaphor is light touch — it does not dominate the UI. The product should feel like a well-organized tool a senior developer built for themselves.

## Anti-references

- Generic SaaS cream-and-blue dashboards (Linear-clone aesthetics applied without purpose)
- Overdecorated job-tracker apps with timelines, confetti, and onboarding carousels
- HR software: busy, permission-heavy, form-heavy

## Design Principles

1. **Tool first.** The interface disappears into the task. No decoration that slows the user down.
2. **Density earns trust.** Users are technical. Show information; don't hide it behind progressive disclosure unless it genuinely reduces noise.
3. **State is signal.** Selected, active, loading, error — each has a clear, consistent visual vocabulary. Ambiguity costs time.
4. **Consistency over surprise.** Same button shape, same form control, same affordance for the same action everywhere.

## Accessibility & Inclusion

WCAG AA minimum. Focus states on all interactive elements. No color-only state indicators.
